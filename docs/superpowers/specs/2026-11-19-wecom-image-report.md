# 企业微信图片报告设计

## 目标

将盘前扫描结果渲染为已确认的“清晰摘要”PNG，并由企业微信群机器人发送，替代当前较长的 Markdown 正文。

## 展示内容

- 标题、交易日及距开盘时间说明。
- SPY、QQQ 趋势摘要和入选数量。
- 每个候选标的显示代码、触发类型、状态、盘前价、盘前涨跌、参考区间和失效位。
- 数据异常标的在底部单独提示。
- 无候选时仍生成图片，明确显示“今日无符合条件标的”。
- 底部保留“顺日线趋势”和“不构成投资建议”的说明。

## 技术方案

- 使用 Pillow 在 Python 进程内生成 PNG，不依赖浏览器或外部图片服务。
- 字体按 `SCANNER_FONT_PATH`、Windows 微软雅黑、Linux Noto Sans CJK 的顺序查找；找不到可用中文字体时明确报错。
- 图片宽度固定为 860 像素，高度随候选数量动态增长；候选数量最多为固定观察池的 9 个。
- 渲染器返回 PNG 字节，发送客户端计算 Base64 与 MD5，调用企业微信机器人 `image` 消息接口。
- 企业微信单图 2 MB 限制在发送前校验，超限时抛出不包含 Webhook 的安全错误。
- `--dry-run` 继续输出 Markdown，便于终端排查；`--send` 改为发送 PNG。

## 云端运行

- GitHub Actions 安装 Noto CJK 字体与 Pillow 依赖。
- Webhook 只从 `WECOM_WEBHOOK_URL` Secret 读取，不写入仓库、日志或异常信息。
- 生成或发送失败时任务返回失败状态，便于在 Actions 中发现。

## 验收标准

- 有候选、无候选和异常数据三种报告均能生成有效 PNG。
- 图片消息请求包含正确的 Base64 和 MD5，且不泄露 Webhook。
- 发送路径只发送一张图片；干跑路径不创建发送客户端，仍输出可读 Markdown。
- 全部现有测试与新增测试通过。
